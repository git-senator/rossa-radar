# Радар Rossa

Находит людей, которые прямо сейчас собираются переехать в Бразилию или купить там жильё.

Читает свежие комментарии под англоязычными роликами про переезд, пенсию и жизнь в Бразилии,
оценивает каждый по намерению и показывает только тех, с кем есть смысл заговорить.

## Зачем он такой

Наивный поиск по словам «buy» и «property» здесь не работает. Разведка по 512 реальным
комментариям показала, что громкое большинство под такими роликами — это местные, злые на
иностранцев, и скептики, спорящие о доходности. Настоящих покупателей единицы, и поиск по
ключевым словам топит их в шуме.

Поэтому классификатор ([`lib/classify.ts`](lib/classify.ts)) считает штрафы так же серьёзно,
как и баллы: враждебный комментарий, спор с автором ролика, самореклама и «я тут уже десять
лет живу» уводят оценку в минус. Наверх поднимается тот, кто говорит о себе, называет срок и
считает деньги.

Баллы складываются в три корзины: **горячий** (от 60), **тёплый** (от 38), **холодный**.

## Что нужно для запуска

Ключ **YouTube Data API v3** — бесплатный, из Google Cloud Console:

1. `console.cloud.google.com` → создать проект
2. APIs & Services → Library → **YouTube Data API v3** → Enable
3. APIs & Services → Credentials → Create credentials → **API key**
4. Ограничить ключ только этим API

Ключ читает публичные комментарии и больше ничего не умеет: ни публиковать, ни заходить в
аккаунт.

## Локально

```bash
npm install
cp .env.example .env.local   # вписать YOUTUBE_API_KEY
npm run dev
```

## Квота

Бесплатный лимит — 10 000 единиц в сутки.

| Что | Стоимость |
| --- | --- |
| Один поисковый запрос | 100 |
| Чтение комментариев одного ролика | 1 |

Скан с настройками по умолчанию (8 запросов × 10 роликов) стоит около **880 единиц** —
одиннадцать сканов в день. Текущая цена показана прямо в шапке приложения.

## Что он не умеет

**Контактов не даёт.** YouTube не отдаёт ни почту, ни телефон комментатора, и не отдаст.
Написать человеку можно только публичным ответом под тем же роликом — личных сообщений
между обычными аккаунтами на YouTube нет с 2019 года.

**Статусы живут в браузере.** Пометки «в работе», «ответили», «не наш» и последний скан
хранятся в `localStorage` — на одном устройстве у одного человека. Для одного оператора
этого достаточно; общая база — первое, что стоит добавить, если радаром начнут пользоваться
вдвоём.
