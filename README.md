# Радар Rossa

Находит людей, которые прямо сейчас собираются переехать в Бразилию или купить там жильё.

Читает свежие комментарии под англоязычными роликами про переезд, пенсию и жизнь в Бразилии,
оценивает каждый по намерению и показывает только тех, с кем есть смысл заговорить.

## Зачем он такой

Наивный поиск по словам «buy» и «property» здесь не работает. Разведка по 512 реальным
комментариям показала, что громкое большинство под такими роликами — это местные, злые на
иностранцев, и скептики, спорящие о доходности. Настоящих покупателей единицы, и поиск по
ключевым словам топит их в шуме.

Сначала это пытались решить правилами на регулярках, и они подвели дважды. Во-первых,
живая речь на них не ложится: «вот бы нам туда, да денег бы хватило» — настоящее намерение,
которого не поймает ни одно правило. Во-вторых, в JavaScript `\b` и `\w` знают только
латиницу, поэтому `/\bхочу/` **не совпадает** с «я хочу», а `/планиру\w*\s/` — с «планирую
купить». Половина русских правил не срабатывала никогда, и «Я хочу купить квартиру в
Бразилии» получало ноль.

Поэтому оценивает модель ([`lib/judge.ts`](lib/judge.ts)). Она видит смысл, а не буквы, и
работает на любом языке без отдельного набора правил под каждый. Ей объясняют, чем торгует
агентство, и она ставит балл от 0 до 100 плюс одну фразу о том, что именно в комментарии
убедило, — эта фраза видна в карточке и в телеграме.

Регулярка осталась ровно одна, перед моделью, и задача у неё обратная — не отобрать лидов,
а отбросить заведомо пустое, чтобы влезть в лимит токенов. Ей достаточно одного тематического
слова в любом месте текста: на живом корпусе из 517 комментариев она оставляет около сорока
и не теряет ни одного известного лида.

Баллы складываются в три корзины: **горячий** (от 60), **тёплый** (от 38), **холодный**.

## Что нужно для запуска

**1. Ключ YouTube Data API v3** — бесплатный, из Google Cloud Console:

1. `console.cloud.google.com` → создать проект
2. APIs & Services → Library → **YouTube Data API v3** → Enable
3. APIs & Services → Credentials → Create credentials → **API key**
4. Ограничить ключ только этим API

Ключ читает публичные комментарии и больше ничего не умеет: ни публиковать, ни заходить в
аккаунт.

**2. Ключ модели** — ею радар оценивает комментарии, без неё лидов не будет вообще.
Подходит любой сервис с OpenAI-совместимым API: переменные `TRANSLATE_API_KEY`,
`TRANSLATE_API_BASE`, `TRANSLATE_MODEL`, примеры в [`.env.example`](.env.example).

Предпочтительно **Gemini**: бесплатный тариф даёт на порядки больший лимит токенов в минуту,
а ключ берётся из того же проекта Google Cloud, что и ключ YouTube. На бесплатном **Groq**
потолок — 8 000 токенов в минуту, этого хватает примерно на один обход в час и ни на что
сверх того; при нехватке часть комментариев останется неоценённой, попадёт в `errors` и будет
пересмотрена следующим обходом.

### Перевод

Тот же ключ используется для перевода комментариев на русский под каждой карточкой. Если
оценку и перевод нужно развести по разным моделям, для оценки задаются отдельные
`JUDGE_API_KEY`, `JUDGE_API_BASE`, `JUDGE_MODEL`.

Переводы кешируются в браузере: один и тот же комментарий переводится один раз.

## Слежка со звуком

Кнопка **«Следить и пикать»** запускает скан по таймеру, пока вкладка открыта.
Как только находится человек, которого раньше не показывали — звучит сигнал, всплывает
уведомление системы и мигает заголовок вкладки, если вы на другой.

Звук синтезируется на месте через Web Audio, файла нет. Браузеры не дают заводить звук
без действия пользователя, поэтому он включается именно кликом по кнопке — рядом есть
«Проверить звук».

Первый скан после очистки памяти намеренно молчит: иначе он зазвонил бы на всех сразу.

Интервал считает расход квоты за сутки и предупреждает, если не влезает. Со списком
каналов слежка дешёвая (канал — 2 единицы), с поисковыми запросами — дорогая (100 за
запрос), так что для круглосуточного режима держите каналы, а запросы включайте руками.

## Квота

Бесплатный лимит — 10 000 единиц в сутки.

| Что | Стоимость |
| --- | --- |
| Один поисковый запрос | 100 |
| Чтение комментариев одного ролика | 1 |

Скан с настройками по умолчанию (8 запросов × 10 роликов) стоит около **880 единиц** —
одиннадцать сканов в день. Текущая цена показана прямо в шапке приложения.

## Что он не умеет

**Контактов не даёт.** YouTube не отдаёт ни почту, ни телефон комментатора, и не отдаст.
Написать человеку можно только публичным ответом под тем же роликом — личных сообщений
между обычными аккаунтами на YouTube нет с 2019 года.

**Статусы живут в браузере.** Пометки «в работе», «ответили», «не наш» и последний скан
хранятся в `localStorage` — на одном устройстве у одного человека. Для одного оператора
этого достаточно; общая база — первое, что стоит добавить, если радаром начнут пользоваться
вдвоём.

## Устройство

| Файл | Что делает |
| --- | --- |
| [`lib/judge.ts`](lib/judge.ts) | Оценка моделью. Здесь подсказка, по которой решается, кто лид |
| [`lib/language.ts`](lib/language.ts) | Отсев португальского и проверка, нужен ли перевод |
